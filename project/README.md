# MAIRIE360 - Site Vitrine

**La solution qui fait le tour complet des mairies**

---

## 📋 À propos du projet

MAIRIE360 est un **prototype de site vitrine** développé dans le cadre d'un **projet de fin d'année d'école**. Il présente une solution SaaS fictive destinée à moderniser la gestion numérique des mairies françaises.

> **⚠️ Important** : Ce projet est **non commercial** et réalisé à des fins pédagogiques uniquement.

---

## 🎯 Objectifs du projet

- Créer un site vitrine moderne et professionnel
- Démontrer la faisabilité d'une plateforme numérique pour les mairies
- Appliquer les bonnes pratiques de développement web (Next.js, TypeScript, React)
- Concevoir une expérience utilisateur attractive et accessible

---

## 🛠️ Technologies utilisées

- **Framework** : Next.js 13.5
- **Langage** : TypeScript
- **Styling** : Tailwind CSS
- **UI Components** : shadcn/ui
- **Icônes** : Lucide React
- **Police** : Montserrat (Google Fonts)

## 🚀 Installation et lancement

### Prérequis

- Node.js 18+ installé
- npm ou yarn

### Installation

```bash
# Cloner le projet (ou décompresser l'archive)
cd mairie360

# Installer les dépendances
npm install
```

### Lancement en développement

```bash
npm run dev
```

Le site sera accessible sur [http://localhost:3000](http://localhost:3000)

### Build de production

```bash
npm run build
```

### Vérification des types TypeScript

```bash
npm run typecheck
```
